Device controls

Hardware buttons

Reset restarts the simulator. QON acts on the charger and has no readable button signal.

Host touchpad

Drag on the pad or display. Touch input supports five contacts. Hold Shift to keep a mouse contact down. Press Escape to cancel all contacts.

Radio scenario

The simulator uses test data for Wi-Fi and Bluetooth LE. It does not scan nearby radios.

GNSS scenario

GNSS observations use test data. Select Diagnostics, then GNSS to see coordinates, satellite signals, and receiver activity.

Power scenario

Power observations use test data. Select Diagnostics, then Power to see battery measurements, charger settings, and faults.

Click the screen or use the device controls. Pause to advance virtual time.
